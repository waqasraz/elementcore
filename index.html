ElementCore

A lightweight, pure JavaScript component framework focused on simplicity and direct DOM manipulation

~8KB Minified Size
0 Dependencies
100% Pure JavaScript

Why ElementCore?

🪶

Lightweight

Minimal core with no dependencies, perfect for performance-critical applications.

⚡

Direct DOM Access

Render once, manipulate directly. No virtual DOM overhead.

🎯

Simple State

Object-based state with manual change handling for precise control.

📦

Component System

Class-based components with lifecycle methods and plugin architecture.

📝

Pure JavaScript

No JSON limitations, full JavaScript object syntax support.

🏗️

Cross-Environment

Works in browser, Node.js, and AMD environments seamlessly.

Quick Start

// Create an ElementCore instance
const app = ElementCore.create(document.getElementById('app'));

// Render your UI
app.render({
    tag: 'div',
    style: { padding: '20px' },
    children: [
        { tag: 'h1', children: ['Hello ElementCore!'] },
        { 
            tag: 'button', 
            children: ['Click me!'],
            onClick: () => alert('Button clicked!')
        }
    ]
});
