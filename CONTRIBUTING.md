# Contributing to ElementCore

Thank you for your interest in contributing to ElementCore! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/elementcore.git`
3. Install dependencies: `npm install`
4. Make your changes
5. Build and test: `npm run build`
6. Submit a pull request

## Development Setup

### Prerequisites
- Node.js >= 14.0.0
- npm or yarn

### Setup
```bash
git clone https://github.com/waqasraz/elementcore.git
cd elementcore
npm install
```

### Building
```bash
npm run build
```

### Running Demos
```bash
npm run demo
# Or open demos/demos.html in your browser
```

## Code Style

- Use ES6+ features where appropriate
- Follow existing code formatting
- Add comments for complex logic
- Keep functions focused and small

## Submitting Changes

### Pull Request Process

1. Create a feature branch: `git checkout -b feature/your-feature-name`
2. Make your changes
3. Add/update tests if applicable
4. Build and verify: `npm run build`
5. Commit with descriptive messages
6. Push to your fork
7. Create a pull request

### Commit Messages

Use clear, descriptive commit messages:
- `feat: add new component lifecycle method`
- `fix: resolve state update issue in ListComponent`
- `docs: update README with new examples`
- `refactor: simplify component registration`

## Reporting Issues

When reporting bugs, please include:
- ElementCore version
- Browser/Node.js version
- Minimal code example that reproduces the issue
- Expected vs actual behavior
- Error messages or console output

## Feature Requests

For new features:
- Explain the use case
- Provide examples of how it would be used
- Consider backwards compatibility
- Be open to discussion and alternative approaches

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help maintain a welcoming environment
- Report inappropriate behavior

## Questions?

- Check existing issues and discussions
- Ask questions in GitHub issues
- Be specific about your use case

Thank you for contributing to ElementCore!
